# Winning and losing

## Which team wins when the Mafia is gone: when the Civilians win
The Civilians (the Town team) win when there are no living Mafia members, that is, when the Mafia is gone and every Mafia player has been eliminated. If you are asking which team wins when the Mafia is gone, it is the Civilians. This can happen after a vote eliminates the last Mafia member, or at the end of a night if the Detective's investigation finds the last Mafia member.

## When the Mafia wins
The Mafia wins when the number of living Mafia is greater than or equal to the number of living non-Mafia players. For example, with one Mafia alive, the Mafia wins as soon as one non-Mafia player is left. The Mafia does not have to eliminate everybody.

Simple version: Town needs every Mafia gone. The Mafia only needs to equal the rest of the village in number.

## When the game checks for a winner
The game checks for a winner twice per round: once when a night is resolved, before the morning report, and once after the votes of the day are counted. If either team has met its condition, the game ends and shows the result screen. Otherwise the next phase begins.

## The result screen
The game-over screen announces which team won and lists every player with their real role and whether they are still alive or out. All roles become public at this point. NEW GAME reloads the page so a new game can be set up.
